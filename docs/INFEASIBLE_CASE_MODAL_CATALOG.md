# 근무표를 못 만들 때 — 안내 문구 모음 (쉬운 말 버전)

근무표를 만들다가 **지금 설정으로는 도저히 못 짜는 경우**, 화면에 뜨는 안내입니다.
누구나(전산 잘 모르셔도) 바로 이해하도록 쉬운 말로 정리했습니다.

**화면 구성**: ① 위에 "무엇이 문제인지" 한 줄 → ② 아래에 "이렇게 하면 됩니다" 버튼 몇 개(누르면 그 값으로 바로 다시 만들어 줍니다).

**근무 종류 말풀이**
- **낮 근무(주간, D)** / **저녁 근무(E)** / **밤 근무(야간, N)** / **휴무(쉬는 날, O)**
- **고정 근무**: 미리 "이 사람은 이 날 이 근무" 하고 정해둔 것
- **연차/직급**: 간호사 등급 · **팀**: 병동 안의 조

## A. 사람이 모자라는 경우 (숫자로 바로 확인)

| 문제 (화면 안내) | 이렇게 하면 됩니다 | 대신 생기는 점 |
|---|---|---|
| 이번 달 채워야 할 근무 자리({required}개)가, 간호사들이 설 수 있는 최대 근무량({capacity}개)보다 {shortage}개 더 많습니다. 지금 인원으로는 다 못 채웁니다. | 간호사를 더 늘리거나, 하루에 필요한 인원을 조금 줄이세요. | — |
| 밤 근무가 필요한 횟수({n_required}번)가, 간호사들이 한 달에 설 수 있는 밤 근무 최대치({n_capacity}번)보다 많습니다. | ① 한 사람이 한 달에 설 수 있는 밤 근무 횟수를 늘려주세요(**얼마로 하면 되는지 자동으로 알려드립니다**). ② "밤 2번 서면 2일 쉬기" 규칙을 잠시 꺼주세요. | ① 특정 사람에게 밤이 몰릴 수 있어요. ② 밤 근무 뒤 쉬는 시간이 줄어요. |
| 어떤 날 필요한 밤 근무 인원({n_required}명)이, 그날 밤 근무 설 수 있는 사람보다 많습니다. | 밤 근무 가능한 간호사를 늘리거나, 그날 밤 근무 인원을 줄이세요. | — |
| {day}일에 필요한 근무 인원({total_demand}명)이 전체 간호사 수({nurse_count}명)보다 많습니다. 모두 나와도 못 채웁니다. | 그날 필요 인원을 간호사 수 이하로 줄이세요. | 그날 근무 인원이 줄어요. |
| {day}일 {shift} 근무를 설 수 있는 간호사({eligible}명)가 필요한 인원({required}명)보다 적습니다. | 그 근무를 설 수 있는 간호사를 늘리거나, 필요 인원을 줄이세요. | — |
| {nurse_id} 간호사에게 "설 수 있는 근무 종류"가 하나도 지정돼 있지 않아, 어떤 근무도 넣을 수 없습니다. | 그 간호사가 설 수 있는 근무(낮/저녁/밤)를 지정해주세요. | — |
| 주말에 무조건 쉬는 간호사({weekend_off_count}명)가 많아, 평일에 일할 사람({weekday_eligible}명)이 평일 필요 인원({weekday_demand}명)에 못 미칩니다. | "주말 무조건 휴무" 설정을 꺼주세요. | 주말 휴무 간호사도 평일에 쉬거나 주말에 일할 수 있어요. |
| 특정 근무만 설 수 있는 간호사가 너무 많아, 다른 근무에 사람이 부족합니다. | 그 간호사들이 다른 근무도 설 수 있게 해주세요. | — |

## B. 설정 숫자가 서로 안 맞는 경우 (설정만 고치면 됨)

| 문제 (화면 안내) | 이렇게 하면 됩니다 |
|---|---|
| {grade} 등급의 "최소 인원"이 "최대 인원"보다 크게 돼 있습니다(숫자가 거꾸로예요). | 최소·최대 인원 숫자를 바로잡아 주세요. |
| {nurse_id} 간호사의 한 달 {shift} 근무 "최소"가 "최대"보다 크게 돼 있습니다. | 그 간호사 월 근무 최소·최대 숫자를 바로잡아 주세요. |
| "중간 근무"를 쓰기로 했는데, 하루 필요 인원에 중간 근무 인원이 빠져 있습니다. | 중간 근무 인원을 넣거나, 중간 근무를 안 쓰기로 바꿔주세요. |
| "중간 근무"를 안 쓰기로 했는데, 다른 설정에서 중간 근무를 쓰고 있습니다. | 중간 근무 사용을 지우거나, 중간 근무를 켜주세요. |
| {nurse_id} 간호사에게 "밤 근무를 정확히 {n_exact}번" 서라고 정했는데, 근무 가능한 날 수나 다른 규칙과 맞지 않아 불가능합니다. | 그 "정확히 몇 번" 값을 조정해주세요. |

## C. 직급·팀 인원 규칙이 빡빡한 경우

| 문제 (화면 안내) | 이렇게 하면 됩니다 | 대신 생기는 점 |
|---|---|---|
| {day}일 {shift}에 직급별 "최소 인원"을 다 더하면 {min_sum}명인데, 실제 필요 인원({required}명)보다 많습니다. | 직급별 최소 인원을 줄이거나, 잠시 느슨하게 해주세요. | 직급 구성이 원하는 대로 안 나올 수 있어요. |
| 직급별 "최대 인원"을 다 더해도 필요 인원에 못 미칩니다. | 직급별 최대 인원을 늘려주세요. | 상위 직급이 많이 배치될 수 있어요. |
| {day}일 {shift}에 팀별 최소 인원을 다 더하면 필요 인원보다 많습니다. | 팀별 최소 인원을 잠시 느슨하게 해주세요. | 일부 근무에 팀 인원이 1~2명 부족할 수 있어요(인수인계 주의). |
| 팀({team_id}) 인원({size}명)이 그 팀에 정한 최소 인원({team_min}명)보다 적습니다. | 팀 인원을 보강하거나, 팀 최소 인원을 낮춰주세요. | — |

## D. 미리 정해둔 근무가 부딪히는 경우 (고정 근무만 손보면 됨)

| 문제 (화면 안내) | 이렇게 하면 됩니다 |
|---|---|
| {day}일 {shift}에 미리 정해둔 근무({fixed_count}명)가 그날 필요 인원({required}명)보다 많습니다. | 넘치는 고정 근무를 빼주세요. |
| {nurse_id} 간호사에게 미리 정한 {shift} 근무가, 그 간호사가 설 수 있는 근무 종류가 아닙니다. | 고정 근무를 바꾸거나, 그 근무를 설 수 있게 해주세요. |
| {nurse_id} 간호사의 미리 정한 휴무·쉬는 날 합계({total}일)가 이 달 근무 가능 일수({span}일)보다 많습니다. | 고정 휴무나 쉬는 날 수를 줄여주세요. |
| {nurse_id} 간호사는 미리 정한 근무({fixed_cells}건)와 개인 규칙(밤→낮 금지·밤 뒤 휴식·연속근무 제한)이 서로 부딪혀, 혼자서는 근무표를 짤 수가 없습니다. | 그 간호사의 고정 근무를 조정하거나, 개인 규칙을 느슨하게 해주세요. |
| {nurse_id} 간호사가 특정 근무를 이 달 내내 못 서게 돼 있어, 다른 근무 인원이 부족합니다. | 막아둔 근무를 일부 풀어주세요. |

## E. 규칙끼리 얽혀서 안 되는 경우 (실제로 다시 계산해 확인)

이 경우 화면 위에는 이렇게 뜹니다:
> **"지금 설정으로는 근무표를 만들 수 없습니다. 아래 중 하나를 바꾸면 만들 수 있어요(실제로 다시 계산해서 확인했습니다)."**

| 왜 안 되나 (화면 안내) | 이렇게 하면 됩니다 | 대신 생기는 점 |
|---|---|---|
| 밤 근무를 2번 연달아 한 간호사들이 그 다음 2일을 꼭 쉬어야 해서, 그 기간에 사람이 부족합니다. | "밤 2번 서면 2일 쉬기" 규칙을 잠시 꺼주세요. | 밤 근무 뒤 쉬는 보장이 약해져요. |
| 밤 근무를 3번 연달아 한 간호사들이 그 다음 2일을 꼭 쉬어야 해서, 그 기간에 사람이 부족합니다. | "밤 3번 서면 2일 쉬기" 규칙을 잠시 꺼주세요. | 밤 근무 뒤 쉬는 보장이 약해져요. |
| "쉬지 않고 최대 며칠까지 일할 수 있는지" 한도가 짧아, 그 기간에 모두가 한 번씩 쉬어야 해서 사람이 부족합니다. | 연달아 일할 수 있는 최대 날수를 늘려주세요(**얼마로 하면 되는지 자동 안내**). | 연달아 일하는 날이 늘 수 있어요. |
| 밤 근무 다음날 바로 낮 근무를 못 하게 한 규칙 때문에, 필요한 낮 근무를 넣을 수 없습니다. | "밤→낮", "저녁→낮" 바로 이어지는 근무 금지를 풀어주세요. | 밤 근무 다음날 낮/저녁 근무가 생길 수 있어요. |
| 미리 정한 밤 근무 양옆이 쉬는 날이라, "밤 근무는 하루만 혼자 서면 안 된다"는 규칙을 지킬 수 없습니다. | "밤 근무 하루만 단독 금지"를 풀어주세요. | 밤 근무를 하루만 서는 경우가 생길 수 있어요. |
| 쉬는 날 바로 전날에는 밤 근무를 못 넣게 한 규칙 때문에, 밤 근무 설 사람이 부족합니다. | "쉬는 날 전날 밤 근무 금지"를 풀어주세요. | 쉬는 날 바로 전날 밤 근무가 생길 수 있어요. |
| 지난달 마지막 날 밤 근무를 선 간호사는, 이번 달 첫날 근무가 밤→낮 이어지는 금지에 걸려 넣을 수 없습니다. | 이어지는 근무 금지를 풀거나, 지난달 마지막 근무를 조정해주세요. | 밤 근무 다음날 근무가 생길 수 있어요. |
| 한 달에 꼭 쉬어야 하는 날 수가 많아, 일할 사람이 부족합니다. | 한 달 필수 휴무 날 수를 줄여주세요. | 쉬는 날이 줄어요. |

## F. 파견·교육(신규 간호사) 관련

| 문제 (화면 안내) | 이렇게 하면 됩니다 | 대신 생기는 점 |
|---|---|---|
| 신규 간호사와 담당 선배가 같이 근무해야 하는데, 두 사람이 함께 설 수 있는 근무가 없습니다. | "신규-선배 함께 근무" 설정을 꺼주세요. | 함께 서며 배우는 교육이 약해져요. |
| 다른 병동에서 파견 온 간호사의 근무 가능 기간({active_days}일)이 필요한 기간({needed_days}일)보다 짧습니다. | 파견 기간을 늘리거나, 대상을 바꿔주세요. | — |
| 우리 병동에서 파견 나간 간호사 때문에 우리 병동에 {shortage}명이 부족합니다. | 파견 기간이나 인원을 조정해주세요. | — |
| 파견 온 간호사가 설 수 있는 근무가, 우리 병동에 부족한 근무와 맞지 않습니다. | 다른 간호사나 다른 근무로 바꿔주세요. | — |

## G. 이유를 바로 못 찾은 경우

| 화면 안내 | 이렇게 합니다 |
|---|---|
| 왜 안 되는지 딱 짚어내진 못했지만, 시스템이 여러 설정을 실제로 바꿔가며 다시 계산해서 **"이것을 바꾸면 됩니다"**를 찾아 알려드립니다(확인된 방법). 그래도 안 나오면 상세 내용을 보고 직접 확인이 필요합니다. | 시스템이 찾아준(확인된) 방법을 눌러 적용하세요. |

## 화면에 뜨는 방식 (요약)

1. **맨 위 한 줄**: 무엇이 문제인지 쉬운 말로. (사람 부족은 숫자까지, 규칙 얽힘은 "이걸 바꾸면 됩니다")
2. **아래 버튼들**: 바꿀 내용 + 대신 생기는 점 + **누르면 그 값으로 바로 다시 만들기**.
3. 사람 부족은 "얼마로 하면 되는지" 값을 자동으로 채워 보여주고, 규칙 얽힘은 "실제로 다시 계산해 확인함" 표시가 붙습니다.

## 프론트 계약 — JSON 구조 (원인 + 어디서 어떻게)

실패 응답 `infeasibility` 안에서 프론트가 읽는 두 배열:

### resolution_options[] (해결 버튼)
```json
{
  "title_ko": "연속근무 상한 완화",
  "verified": true,                         // probe 재계산으로 확인됨
  "trade_off_ko": "연속 근무일이 늘어날 수 있습니다.",
  "changes": [{"config_key": "max_conseq_work", "from": 2, "to": 3}],
  "apply": {"max_conseq_work": 3},          // 그대로 apply-resolution 로 재생성
  "fix": {                                  // ★ 어디서 어떻게
    "mode": "auto_apply",                   // auto_apply | manual_edit | manual_navigate
    "where": "roster_config.max_consec_work",   // 프론트 라우팅 의미키
    "where_label_ko": "설정 > 근무 규칙 > 연달아 일하는 최대 날수",
    "how_ko": "3(으)로 바꾸세요 (아래 버튼으로 바로 적용됩니다).",
    "config_key": "max_conseq_work",
    "target": null
  }
}
```

### causes[] (데이터성 원인 — 이동해서 직접 수정)
```json
{
  "reason_code": "MONTHLY_LIMIT_MIN_EXCEEDS_MAX",
  "human_message_ko": "...월 min이 max보다 큽니다...",
  "fix": {
    "mode": "manual_navigate",
    "where": "nurse.monthly_limit",
    "where_label_ko": "간호사 관리 > 해당 간호사 > 월 근무 한도",
    "target": {"nurse_id": "n5"}            // 딥링크 컨텍스트
  }
}
```

### `where` 의미키 → 프론트 라우팅 (계약)
| where | 실제 화면(프론트가 매핑) |
|---|---|
| `roster_config.*` (night_month_limit·max_consec_work·recovery_2n·transition·weekend_off·off_days·team_min·grade·daily_need·preceptee·mid) | 근무표 설정 모달의 해당 항목 |
| `nurse.allowed_shifts` / `nurse.monthly_limit` | 간호사 관리 > 해당 간호사(딥링크 nurse_id) |
| `fixed_shift.edit` | 고정 근무 편집(딥링크 day/nurse_id) |
| `dispatch` | 파견 관리 |
| `nurse.roster` | 간호사 인원 추가 |

**mode 의미**: `auto_apply`=버튼으로 그 값 바로 적용→재생성 / `manual_edit`=그 설정 화면서 직접 수정 / `manual_navigate`=대상(간호사/날짜)으로 이동해 수정.

구현: `app/services/cp_sat/fix_location.py` (매핑) — `undiagnosed_probe.to_resolution_options`/`treatments_to_resolution_options`가 옵션에, `precheck/payload.py` 빌더가 cause에 `fix` 부착. 테스트 `tests/test_fix_location.py`.
