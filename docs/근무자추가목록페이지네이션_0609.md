# 근무자 추가 목록 페이지네이션_0609

## 작업 범위

- `/nurses/available-members` 엔드포인트만 cursor pagination 방식으로 변경했다.
- 기존 `/nurses/add-to-group` 저장 API와 `/nurses` 목록 API는 변경하지 않았다.

## 변경 내용

- Query
  - `group_id`: 기존과 동일하게 필수
  - `q`: 검색어
  - `search_by`: `name` 또는 `affiliation`, 기본값 `name`
  - `cursor`: 다음 페이지 cursor
  - `limit`: 기본 20, 최대 100
- Response
  - `items`: 현재 페이지 근무자 목록
  - `next_cursor`: 다음 페이지 요청 cursor
  - `has_next`: 다음 페이지 여부
  - `total`: 검색/제외 조건 기준 전체 건수

## 구현 메모

- 기존처럼 현재 `group_id`에 이미 등록된 `nurse_id`는 제외한다.
- MSSQL 병원 멤버 전체를 가져온 뒤 파이썬에서 자르지 않고, MSSQL 쿼리에 이름 검색, 제외 ID, cursor 조건, `FETCH NEXT limit + 1`을 적용한다.
- 정렬 기준은 `EmployeeName ASC`, `EmpSeqNo ASC`로 고정해 cursor 페이지가 안정적으로 이어지도록 했다.

## 2026-06-09 검색 기준 추가

- `/nurses/available-members`에 `search_by` 쿼리스트링을 추가했다.
- `search_by=name`은 `EmployeeName` 기준으로 부분검색한다.
- `search_by=affiliation`은 `big_kind_name`, `middle_kind_name`, `small_kind_name`, `mb_part_name` 기준으로 부분검색한다.
- `search_by`가 없거나 잘못된 값이면 기존 호환을 위해 `name`으로 처리한다.
