# 근무표 생성 파라미터 안내 (비개발자용)

> 근무표 자동생성 엔진이 사용하는 모든 설정값을, 병동 관리자·수간호사가 이해할 수 있게 정리한 문서입니다.
> 기준 파일: `app/db/roster_config.py`, `app/services/cp_sat/hardcoded_weights.py`, `app/services/cp_sat/objective_terms.py`

---

## 먼저 알아둘 것

### 1) 코드 기본값 ≠ 화면에 뜨는 값
설정 화면(모달)에 보이는 `D4·E3·N3`, `월 OFF 9일`, `연속 5일` 등은 **코드 기본값이 아니라 저장된 프리셋("2병동 기본 설정") 값**입니다.
아래 표에서 **코드 기본값**과 **화면 예시값**을 나눠 표기했습니다.

### 2) 가중치(점수)는 우선순위를 정하는 숫자
③번 표의 숫자들은 전부 **점수(벌점·상점)**입니다.
엔진은 근무표를 만들 때 규칙을 어기면 벌점을, 좋은 배치를 하면 상점을 매기고 **총점이 가장 좋은 표를 고릅니다.**
따라서 **숫자가 클수록 그 규칙을 더 세게(우선) 지킨다**는 뜻입니다.

## ① 화면(설정 모달)에서 직접 조정하는 값 — 10개

| 화면 항목 | 코드 기본값 | 화면 예시값 | 의미 |
|---|---|---|---|
| 기본 필요 인원 (D·E·N) | D3·E3·N2 | D4·E3·N3 | 근무별 하루 최소 인원 |
| 날짜별 필요 인원 | 없음 | 날짜별 설정 | 특정 날만 인원 다르게 |
| 프리셉티 인원 포함 | 켜짐 | 켜짐 | 교육생을 인원수에 셀지 |
| 월 OFF 일수 | 8일 | 9일 | 개인 휴무 일수 |
| 주휴 적용 | 꺼짐 | 켜짐 | 주당 2일 휴무 보장 |
| OFF 초과 시 휴가 처리 | 켜짐 | 켜짐 | 기준 초과 OFF를 연차로 처리 |
| 연속 근무 최대 | 6일 | 5일 | 며칠까지 연속 근무 허용 |
| 나이트 연속 최대 | 3일 | 3일 | 야간 연속 상한 |
| 원티드 적용 | — | 켜짐 | 간호사 근무 신청 반영 여부 |
| 우선 적용 기준 | OFF 우선 | 인원 우선 | 인원 채우기 vs OFF 보장 중 우선순위 |

## ② 화면엔 없지만 자동으로 적용되는 규칙 (on/off · 한도)

사용자가 화면에서 보거나 바꿀 수 없지만, 근무표에 실제로 작용하는 규칙들입니다.

| 항목 | 기본값 | 쉬운 설명 |
|---|---|---|
| 저녁→다음날 아침 금지 (E→D) | 켜짐 | 저녁 근무 후 다음날 아침 근무 금지 (법규) |
| 월 최대 나이트 | 15개 | 한 달 야간 상한 |
| 공통 휴무일 | 3일 | 공휴일 등 전원 공통 OFF |
| 시니어-주니어 동반 | 켜짐 | 신규(≤2년)는 시니어(≥6년)와 함께 근무 |
| 나이트 직전 휴가 보호 | 켜짐 | 휴가/휴무 바로 전날 야간 배치 금지 |
| 나이트 개수 균등 | 켜짐 | 야간을 특정인에게 몰지 않음 |
| 나이트 블록 간격 목표 | 10일 | 야간 몰아친 뒤 다음 야간까지 텀 유지 |
| 시프트 쏠림 상한 | 1.5배 | 개인 D/E/N이 서로 1.5배 넘지 않게 |
| 데이-이브닝 균등 | ±2일 | 개인의 D·E 개수 차이 허용 한도 |
| OFF 붙여 배정 | 켜짐 | 휴무를 몰아서(연달아) 배치 |
| 여유 OFF 추가 허용 | 3일 | 필요할 때만 OFF 추가 |
| 같은 시프트 4연속 방지 | 켜짐 | 예: D D D D 억제 |
| 단발 야간(1N) 금지 | 꺼짐 | 기본은 허용 |
| 4연속 OFF 금지 | 꺼짐 | 기본은 허용 |
| 주말 휴무자 평일 OFF 금지 | 켜짐 | 주말휴무 대상자는 주말에만 OFF |
| 초과 인원 균등 | 켜짐 | 남는 인원을 요일별 고르게 |
| 야간전담 우선 배치 | 켜짐 | 나이트 전담자는 야간에 우선 |
| 팀 균형 배분 | 꺼짐 | 팀별 몰아주기 (게이지 0~10) |
| 프리셉티 팔로우 | 꺼짐 | 교육생이 사수 근무를 따라감 |
| 미드(M) 근무 사용 | 꺼짐 | 낮·저녁 사이 근무 추가 |
| 배분 방식 | 하이브리드 | 균등 + 선호 섞어서 배분 |
| 생성 시간 제한 | 60초 (고급 180초) | 최적표 탐색 시간 |
| 병렬 처리 | 8갈래 동시 | 여러 후보를 동시에 계산 |

## ③ 엔진 품질용 점수(가중치) — 전부 포함, 센 순서대로

**"이 규칙을 얼마나 우선할지"를 정하는 점수 사다리입니다.**
**위로 갈수록 강해서, 규칙끼리 충돌하면 위쪽이 이깁니다.**

| 점수 | 무엇에 대한 점수인가 | 쉬운 설명 |
|---:|---|---|
| **1,200,000** | 사람 간 근무량 형평성 | 근무 부담을 사람마다 고르게 (제일 강함) |
| **500,000** | 시프트 쏠림 상한 | 개인 D/E/N이 1.5배 넘으면 큰 벌점 |
| **300,000** | 고립 OFF 방지 | 휴무 하루만 뚝 떨어져 있는 것 억제 |
| **160,000** | 등급(숙련도) 비율 | 근무마다 필요한 등급 인원 맞추기 |
| **100,000** | 인원 부족 / 근무시간 형평 | 필요 인원 못 채우는 걸 강하게 방지 |
| **80,000** | 팀 인계 제한 | 특정 등급끼리 같은/인접 근무 제한 (쓸 때만) |
| **50,000** | 연속 OFF 붙이기 (상점) | 휴무를 이어붙이면 상점 |
| **10,000** | 같은 시프트 4연속 방지 | D D D D 같은 반복 억제 |
| **5,000** | 야간 개수 불균형 방지 | 야간이 한 사람에 몰리면 벌점 |
| **1,500** | 고립 근무(퐁당퐁당) 방지 | 근무-쉼-근무 끼임 억제 |
| **500** | 야간전담 보너스 / 팀 최소인원 미달 | 전담자 야간 배치 상점, 팀 인원 미달 벌점 |
| **300** | 주 2회 OFF 부족 / N-O-D·E 패턴 | 주휴 부족·특정 패턴 억제 |
| **200** | 경력자 부족 | 근무에 경력자 없으면 벌점 |
| **180** | 연속근무 초과 (소프트) | 상한 넘겨 일하면 벌점 |
| **120** | 초과 인원 균등 | 남는 인원을 요일별 고르게 |
| **100** | 고립OFF(보조)·경력자(폴백)·선호 배율 | 세부 조정용 |
| **80** | 여유 OFF 억제 / 3연속 야간 유도 | 불필요한 OFF·2N블록 억제 |
| **60** | 개인 월 선호 보너스 | 간호사 개인 신청 반영 상점 |
| **50** | 야간 블록 간격 | 야간 텀 10일에서 멀어지면 약한 벌점 |

### 개인 선호 배율 (참고)
- 원하는 근무 D / E / N = 각 **5점**
- 원하는 휴무(OFF) = **10점** (휴무 선호를 근무 선호보다 2배 존중)
- 경력자 가중 = **1.5배**
- 페어(짝) 선호 = **3배**

### 후처리 보너스 (참고)
표를 다 만든 뒤 미세 조정하는 배수입니다.
- 팀 균형 후처리 = **0.2배**
- 등급 전략 후처리 = **0.5배**

## 세 줄 요약

- 화면에서 **직접 만지는 건 10개**뿐입니다.
- 뒤에서 **자동으로 켜지는 규칙이 20여 개** 있습니다 (법규·안전·삶의 질).
- 그 규칙들을 **얼마나 세게 지킬지 정하는 점수가 ③번 사다리**입니다 — 형평성(120만)이 가장 세고, 야간 간격(50)이 가장 약합니다.
