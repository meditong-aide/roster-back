# analyze-report

## Applicable When
- User asks for "분석", "리포트", "공정성", "편차", "연속 패턴", "부족 날짜"
- Examples: "야간 편차 분석", "연속 3일 이상 야간 사람 찾아줘", "Grade 1 없는 날짜"

## Steps
1. Resolve target schedule and time range
2. Query schedule data
3. Run requested analysis (variance, consecutive patterns, coverage gaps, etc.)
4. Format results as a clear report with actionable findings
