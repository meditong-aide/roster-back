# repair-schedule

## Applicable When
- User asks to "조정", "수정", "재배치", "밸런스", "편차 줄여"

## Steps
1. Analyze current schedule state (identify the problem)
2. Determine repair strategy (parameter tweak + regenerate, or manual swap suggestions)
3. Preview the proposed changes
4. Apply after approval
